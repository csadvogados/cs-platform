# Frontend CS Platform v5.5.0

Frontend estático, sem dependências de JavaScript, conectado à API FastAPI da CS Platform.

## Arquivos principais

- `index.html`: estrutura das telas;
- `assets/styles.css`: identidade visual e responsividade;
- `assets/app.js`: autenticação, navegação e integração com a API;
- `config.js`: endereço do backend;
- `Dockerfile`, `nginx.conf` e `railway.json`: publicação como serviço no Railway.

Para instruções de aplicação e publicação, consulte `README_PRIMEIRO.md` na raiz do pacote.
